Engine design rules R1 to R7

Date: 2026-10-24. Source: specs/platform-systems/ai-quality/19-INTELLIGENCE-ENGINE-SPEC.md section 3 (REQ-R285-AIQ-ENGINE-DESIGN-RULES). Approved by: D372 (R1), D408 (T1 to T21 as written), spec 7 criteria for R2 (REQ-R285-AIQ-T18-INJECTION-HARDENING, D345). This file restates the rules so a builder can read them before the first tool or multi step flow lands. The spec stays canonical. If this file and the spec disagree, the spec wins and this file is corrected.

R1 Workflow, not autonomous agents (D372)

Code decides the path of a bid. A model never chooses the next step. Parallelism is allowed only for independent stages (extraction chunks, evidence search per question). Check: no tools=, function_declarations or tool_config appears in api/app/services or api/app/routers without a row that cites R2.

R2 Plan Then Execute and Context Minimisation

The plan and any tool list are fixed from trusted input before untrusted text is read. A step that reads a tender pack or a supplier reply returns typed data only. A deterministic reducer combines per chunk results. This rule is written before the first tool lands (spec 19 T18 criterion, buy_eval_consistency.py is the model). Enforced in code (D411): api/app/services/ai/plan_then_execute.py freezes a plan with a digest and refuses a changed plan or an unlisted tool. The bulk draft freezes its questions, order, approved outlines and start state at enqueue and the worker verifies the digest before any credit is spent. Supplier text is masked of the bidder's name before the Buy pre-read reads it, and every draft is checked against the text its model calls were shown (draft_response, the shared planted instruction guard).

R3 The deterministic result always wins

A model verdict never overrides a gate (api/app/services/eval/judges.py rule). The figure gate, credential cards and commitment checks run after every model step.

R4 Quote or drop

Any model verdict about evidence carries a verbatim quote that the code finds in the source, or it is discarded.

R5 Organisation scoped memory

Every memory item (style rule, assessment score, graph node, library fact) is keyed by organisation_id and read through the same tenancy re-check as retrieval (retrieval.py:859). No tenant content sits in a prompt prefix shared by design.

R6 Stable prefix first

Prompts put the stable shared block first and the question last so caching can hit (T12). A test asserts the stable block precedes any per question text for each drafting surface.

R7 Plain words in front, detail behind

Every engine signal reaches the user as one plain statement with one action (RULE 0-U). Jargon, model names and section numbers appear only behind a tooltip or an advanced panel.

How to use this file

Before building any T item, name which rules bind it in the PR body. A change that breaks a rule needs a written owner approval quoted in the PR.
