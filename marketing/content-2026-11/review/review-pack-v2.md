## Truth rules applied
- Every line has a source on the current build. If it could not be sourced it was cut.
- CUT: "Primary data stored in the EU" is NOT on the website (checked astro/src), so it is not used in any script.
- The "no AI" claim uses the exact on-screen words: the Opportunities screen shows "No AI in the loop." and the evaluation screen computes the headline deterministically, scores are evaluator set (page.tsx:2-3). Scripts say "scored the same way every time, no AI in the loop", which matches.
- No numbers, no customer names, no "trusted by". Public AND private work named. PPN 026 only. No em dashes.
